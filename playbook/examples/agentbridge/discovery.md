# Discovery brief — AgentBridge Africa

## Problem
Multi-step agent demos collapse under intermittent connectivity, tool latency, and cost overruns; local payment/identity rails are missing from generic agent kits.

## Users / stakeholders
- Platform engineer building agent systems for NG/KE
- Product owner needing predictable cost ceilings

## Success metric
Eval harness at 100% on golden trajectories including failure modes.

## Constraints
- Hard budget stop (not soft warning)
- Offline fails closed
- Side-effect tools need idempotency keys
